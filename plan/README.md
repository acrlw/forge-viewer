# Development plans

Only two files in this directory describe current work:

- [STATUS.md](STATUS.md): supported baseline, known gaps, and immediate priorities;
- [ROADMAP.md](ROADMAP.md): remaining release milestones and their acceptance commands.

The other files are completed implementation records:

- [WGPU_BACKEND.md](WGPU_BACKEND.md): how the wgpu backend was brought to feature parity;
- [UI_REFACTOR_IMPLEMENTATION.md](UI_REFACTOR_IMPLEMENTATION.md): the UI redesign brief and
  acceptance history.

Historical plans explain why code was shaped a certain way, but they are not current usage
documentation. User workflows, configuration, renderer behavior, and API reference live in
[`docs/`](../docs/index.md). `make help` is the maintained Make target catalog.
